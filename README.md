# ⚡ GLYPHSTORM

Single-file Kotlin bullet-heaven × bullet-hell roguelite for Android.
Generated by glyphstorm.sh (chunks A–E). Zero assets: emoji/unicode visuals,
chiptune audio synthesized at startup.

Build: open folder in Android Studio ▶, or:
    gradle wrapper --gradle-version 8.7 && ./gradlew assembleDebug

Monetization: AdMob (test ids in CONFIG at top of glyphstorm.sh).
Rewarded revive (1/run) · rewarded ×2 shards (1/run) · banner (menu/death)
· interstitial (every 3rd death). Swap AdIds + manifest app id before release.
